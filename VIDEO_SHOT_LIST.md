# VOYNICH Trailer Shot List

Target length: 50 seconds.

Use only real in-game footage plus the black-screen text cards listed here. Enable `TRAILER_MODE = true` in `game.js` before capture. Use `F10` to toggle cinematic capture mode so prompts, objectives, and debug indicators are hidden while recording.

## Capture Prep

1. Set `TRAILER_MODE = true`.
2. Open `index.html` directly in the browser.
3. Click or press a key to unlock audio.
4. Open Settings and set grain / scanlines to taste for capture.
5. Start the game.
6. Use the shortcuts listed for each shot.

## Notes

- Keep capture mode on for atmospheric shots and off only when a UI shot is intentionally needed.
- Do not use footage from outside the game.
- Do not add external footage, fake screenshots, or non-game artwork.
- Keep text cards black with sharp light text.
- Avoid rapid flashing; hold each horror image long enough to read the composition.
