# VOYNICH Audio Guide

The canonical editable audio slot list lives at `assets/audio/AUDIO_GUIDE.md`.

That file documents every filename currently referenced by `game.js`, including title music, corridor ambience, archive ambience, manuscript puzzle music, distorted corridor music, ending music, UI sounds, door sounds, paper sounds, puzzle sounds, impacts, glitches, electrical hum, flicker, and distant footsteps.

The game must continue to run when those files are missing. Add only original, commissioned, or properly licensed audio, then update the Credits screen and project documentation with creator, license, and source information before release.
