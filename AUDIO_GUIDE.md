# VOYNICH Audio Guide

The canonical editable audio slot list lives at `assets/audio/AUDIO_GUIDE.md`.

That file documents the complete 22-file MP3 pack currently integrated by `game.js`, including title music, normal and distorted ambience, ending music, UI, dialogue tick, flashlight, document, mechanism, combat, impact, and notification sounds.

The game must continue to run when files are missing or playback is blocked. Add only original, commissioned, or properly licensed audio, then update the Credits screen and project documentation with creator, license, and source information before release.
